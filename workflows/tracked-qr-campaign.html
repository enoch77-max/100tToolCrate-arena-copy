QR workflow · 4 checked steps

Create a trackable QR code for an offline campaign

Build a consistently tagged campaign URL, generate a scannable QR code, test it on a phone, and prepare a clear printed label.

Time neededAbout 10 minutes
Useful forLocal businesses, event organizers, restaurant owners, and campaign teams
0 of 4 steps completeSaved only on this device
Open each tool in a new tab, then mark the step done when the output is checked.

A QR code only records the destination you give it. Without campaign parameters, offline visits blend into direct traffic and become difficult to evaluate. A consistent naming convention is more valuable than an elaborate code design.

Plan the destination before printing. The landing page should work well on mobile, match the promise beside the code, and remain available for as long as the printed material circulates.

1

Tag the destination URL

Use lowercase campaign values your team can recognize later. Keep source and medium stable across every poster in the same placement, and use content to distinguish creative or location variants.

  • Example medium: qr
  • Example source: storefront or event_poster
  • Use a documented campaign naming convention

Tool: UTM Link Builder · Build tracking URLs for Google Analytics campaigns.
2

Generate the code from the final URL

Paste the complete tagged URL and avoid unnecessary visual complexity. Long URLs create denser codes, so a concise destination can improve scanning while retaining the campaign data.

  • Dark foreground on a light background
  • Preserve quiet space around the code
open_in_newGenerate campaign QR using QR Code Generator (opens in a new tab)
Tool: QR Code Generator · Create a custom QR code from text or URL.
3

Test the printed-size result

Scan with more than one phone when possible and check that the landing page retains the expected query parameters. Test under the lighting and at the distance people will actually use.

  • Test from the final printed proof
  • Confirm the destination uses HTTPS
open_in_newTest the QR code using QR Code Scanner (opens in a new tab)
Tool: QR Code Scanner · Scan QR codes using your device camera or selected image.
4

Add an instruction and destination cue

People need a reason to scan. Add a short action such as ‘View the menu’ or ‘Get the event schedule,’ and include a readable fallback URL for anyone who cannot use the code.

  • State the benefit beside the code
  • Do not place the code over folds or reflective surfaces

Mistakes to avoid

Changing UTM capitalization between assets

Analytics tools can treat case variants as separate values. Keep a shared naming sheet for source, medium, campaign, and content.

Testing only on a large monitor

A code that scans at desktop size may fail on a small flyer. Print a proof at the final physical size and viewing distance.

Using a destination you cannot maintain

Printed material outlives many web campaigns. Choose a durable landing page or a redirect process you control.

Frequently asked questions

Does a QR code track scans by itself?add

A standard static QR code simply encodes a destination. Measurement comes from the landing-page analytics and campaign parameters, subject to consent and browser privacy settings.

Can I edit the URL after printing?add

Not inside a static printed code. To change destinations later, print a stable URL you control and manage its redirect or landing content.

Are UTM parameters personal data?add

They normally describe a campaign rather than a person. Do not place names, email addresses, or other personal identifiers in campaign parameters.
