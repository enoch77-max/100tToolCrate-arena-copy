SEO workflow · 4 checked steps

Run a pre-launch SEO check on a new page

Check a page's slug, search snippet, social preview, content focus, and crawler rules before you publish or request indexing.

Time neededAbout 15 minutes per page
Useful forSite owners, content editors, indie hackers, and web developers
0 of 4 steps completeSaved only on this device
Open each tool in a new tab, then mark the step done when the output is checked.

A page can look finished in a design review while still having a duplicate title, an unfinished social card, or a crawler rule carried over from staging. These are inexpensive to fix before launch and annoying to correct after URLs have been shared.

This workflow checks specific deliverables. It does not promise rankings: relevance, competition, links, technical accessibility, and search-engine decisions remain outside any checklist's control.

1

Create a stable, readable slug

Turn the working title into a short URL that reflects the page topic. Remove dates and campaign wording unless they are genuinely part of the content, then keep the published slug stable.

  • Use lowercase words separated by hyphens
  • Avoid keyword stuffing and stop-word-only URLs

Tool: Slug Generator · Convert any title into a URL-friendly slug.
2

Write a distinct search title and description

Check the title for clarity and length, then write a description that accurately sets expectations. Put the distinguishing information in the visible copy rather than repeating the same phrase in every field.

  • One unique title per indexable page
  • Match the actual page purpose
open_in_newCheck the title tag using Meta Title Length Checker (opens in a new tab)
Tool: Meta Title Length Checker · Check if your SEO title is within optimal length limits.
3

Preview the social share

Inspect how the title, description, canonical URL, and image work together when the page is shared. Use an image that remains understandable at small sizes and test the final public URL after deployment.

  • Use an absolute public image URL
  • Avoid text too close to the image edges
open_in_newPreview social metadata using Open Graph Previewer (opens in a new tab)
Tool: Open Graph Previewer · Inspect social metadata through a bounded server fetcher, with explicit network, privacy and platform-rendering limitations.
4

Check content focus and crawler directives

Review natural phrase coverage without chasing a density target. Then verify robots and AI-crawler rules intentionally reflect your policy, and ensure staging blocks are not present on the production page.

  • Keep important pages internally linked
  • Test robots.txt and meta robots separately

Mistakes to avoid

Optimizing for a pixel count alone

Search displays vary by device and query. A title should communicate the topic clearly even when it is not truncated.

Using keyword density as a target score

Repetition can make copy worse. Cover the subject, define terms, answer real questions, and use descriptive internal links instead.

Requesting indexing before the page is public

Verify the canonical, status code, robots rules, and rendered content on the live URL before submitting it to search tools.

Frequently asked questions

Will this checklist make a page rank?add

No checklist can guarantee rankings. It helps catch avoidable publishing errors; search performance also depends on usefulness, competition, discovery, links, and search-engine evaluation.

How long should a meta description be?add

Write a concise, accurate summary and inspect it in a preview. Search engines may rewrite descriptions or choose page text, so there is no guaranteed display length.

Should every page be submitted for indexing?add

Submit important new or substantially updated canonical pages. Keep thin internal search results, duplicates, and private pages out of the indexable set.
