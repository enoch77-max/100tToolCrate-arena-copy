REST quick start

List executable tools and their schemas:

curl https://100toolcrate.com/api/v1/tools

Format JSON with a real execution call:

curl -X POST https://100toolcrate.com/api/v1/tools/json-formatter/execute \
  -H 'Content-Type: application/json' \
  -d '{"json":"{\"ok\":true}","indent":2}'

MCP quick start

Connect a client to https://100toolcrate.com/api/mcp. The server supports initialize, ping, tools/list and tools/call over Streamable HTTP JSON responses.

{"jsonrpc":"2.0","id":1,"method":"tools/call",
 "params":{"name":"word-counter",
 "arguments":{"text":"one two three"}}}

Machine-readable server card · OpenAPI specification

Data handling and limits

Execution inputs and outputs are processed transiently and are not persisted by the execution endpoint. Do not send secrets, personal data, access tokens or regulated datasets. Requests are limited to 16 KB, results to 256 KB, and calls are rate limited. This is different from free browser tools, where supported file processing stays on your device, and from paid services, where files are transferred only through an agreed channel.
