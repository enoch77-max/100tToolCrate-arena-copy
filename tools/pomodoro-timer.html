About Pomodoro Timer

Pomodoro Timer: Focus in Short, Repeatable Blocks

The Pomodoro technique breaks work into focused intervals, traditionally 25 minutes, separated by short breaks. After four focus sessions you take a longer break. This timer implements that cycle with adjustable focus, short-break and long-break lengths, a session counter and an optional automatic start for the next interval.

The countdown is based on an end timestamp rather than a simple tick counter, so it catches up correctly if the tab is backgrounded or the device briefly sleeps. A chime plays when each interval ends. Everything runs in the browser; no account, timer server or notification permission is required.

Getting the Most From It

Decide on one task before starting a session, close unrelated tabs and keep the timer visible if you find that helpful. Use the break to stand up, look away from the screen and reset your attention. If 25 minutes feels too long, start with 15 or 20 and increase gradually.

Frequently asked questions

What is the Pomodoro technique?add

It is a time-management method created by Francesco Cirillo. You work on one task for a fixed interval (usually 25 minutes), take a short break, and repeat. After four focus sessions, you take a longer break. The rhythm makes sustained focus easier to start and easier to measure.

Does the timer keep running in the background?add

The timer stores an end timestamp, so it calculates the correct remaining time when the tab becomes active again. Browsers may throttle background timers, which can delay the chime, so keeping the tab open and audible gives the most reliable experience.

Can I customise the focus and break lengths?add

Yes. Change the focus, short-break and long-break minutes, and choose how many focus sessions trigger a long break. The new values apply to the next interval and to the current interval when it is not running.

Does it send notifications?add

No. It plays a short chime through the Web Audio API when an interval ends. The tool does not request system notification permission.
